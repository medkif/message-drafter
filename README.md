# Message Drafter
Message Drafter is a personal project for generating draft greetings that can be sent to personal acquaintances on a scheduled Cloud Run Job.

#### Goal
The goal of the project is to learn how to build python native solutions that can be hosted and maintained in the cloud. This will facilitate other projects where I can utilize the same architecture. Thus the central components in this repo is not the source code in itself (although the modules developed can be reused) but the CI/CD pipelines and the IaC.
